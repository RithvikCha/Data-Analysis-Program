# Data-Analysis-Program
The Data Analyzer Program is an interactive, terminal-based data analysis and visualization tool written in Python that is designed for rapid data auditing, descriptive statistics, automated pattern discovery, high-resolution plotting, and integrated AI-powered pattern analysis using Google Gemini and local LLMs via Ollama.
Core Capabilities & Features:
When it comes to data ingestion, the tool offers flexible options allowing you to either paste tab-delimited blocks directly from Microsoft Excel and Google Sheets or enter data row-by-row through an interactive prompt. Once your data is loaded, the engine runs an automated availability audit to flag any missing qualitative or quantitative fields, followed by a comprehensive descriptive statistical report that calculates means, medians, modes, median absolute deviations, variance, standard deviations, min/max ranges, and grouped category metrics. Furthermore, its automated pattern discovery engine actively scans your dataset for moderate to strong linear correlations, detects anomalies and outliers based on standard deviation thresholds, and pinpoints performance extremes across your categories.
Rich Visualizations & AI Integration:
For visual analysis, the application leverages matplotlib and seaborn to render clean charts with options to export high-resolution PNGs at 300 DPI. You can effortlessly generate grouped bar charts, scatter plots complete with automatic trendlines and equation overlays, strip and dot distribution plots, donut and pie charts, multi-variable correlation heatmaps, and structured graphical data tables. Additionally, the built-in AI integration module formats your dataset payload, summary statistics, and correlation matrices into a structured prompt, allowing you to query Google Gemini or a local Ollama model directly from your terminal to extract custom insights and pattern reports.
Installation & Prerequisites:
To run the project, ensure you have Python 3.8 or higher installed on your system. You will need to install the core data science and visualization libraries by running pip install matplotlib numpy pandas seaborn. If you plan to use the AI pattern analysis features, you can optionally install the Google Gemini SDK via pip install google-genai or the local Ollama library via pip install ollama (which requires a running local Ollama server instance).
Usage & Workflow:
To start the application, simply execute the script from your terminal using python main.py. You will be guided through defining your study title, observational unit identifier, and your custom categorical and numerical columns. After importing your data, the engine will output its audit and descriptive statistics, dropping you into an interactive menu where you can generate any of the six chart types, run AI overview queries, or exit the session. If you are using the Google Gemini integration, you can supply your API key interactively when prompted or streamline your workflow by setting your API key as an environment variable (export GEMINI_API_KEY="your-api-key-here" on Linux/macOS or set GEMINI_API_KEY="your-api-key-here" on Windows). You can obtain your key for free from Google AI Studio.
